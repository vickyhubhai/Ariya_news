# Ariya News 📰

Official developer news repository for **Ariya**, a modern open-source music player.

This repository provides update announcements, release notes, feature updates, and important news that can be consumed by the Ariya application.

---

## 🎵 About Ariya

**Ariya** is a modern music player built with a focus on:

- Fast and smooth playback
- Clean modern UI
- Music discovery
- Powerful queue management
- Lyrics
- High-quality audio
- Personalization
- Discord Rich Presence
- Native Android experience

Ariya is designed for people who want a clean and enjoyable way to experience their music.
