# Ariya v1.0 Beta is Here! 🎉

Welcome to the first public beta of **Ariya**.

Ariya is built from scratch with native Jetpack Compose, focusing on speed, clean design, smooth playback, and a better music discovery experience.

## What's New

- **Dual Home**: Spotify-powered recommendations like Daily Mixes and Discover Weekly alongside the YouTube Music catalog.
- **High-Quality Audio**: Opus/AAC playback with FLAC fallback where supported.
- **YDS 2.1**: Glassmorphism cards, floating islands, Monet theming, and morphing headers.
- **3-Tier Lyrics**: Original lyrics, Romaji, and live AI-powered translation.
- **Improved Player**: Smoother controls, queue management, and an enhanced now-playing experience.
- **Better Discovery**: Improved recommendations, recently played content, and music discovery.
- **Discord Rich Presence**: Show what you're currently listening to on Discord.

## 🧪 Beta Status

Ariya is currently in public beta.

If you find a bug or unexpected behavior, please report it with:

- A screenshot or screen recording
- Your device model
- Android version
- A short description of what happened

Your feedback helps us improve Ariya.
