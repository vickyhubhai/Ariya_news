# Ariya v1.0.1 is Here! 🚀

Ariya v1.0.1 is now available with important bug fixes, stability improvements, and a smoother overall music experience.

## What's New

### 🛠️ Bug Fixes
- Fixed Online Together session issues.
- Fixed room joining and session state handling.
- Fixed approval mode behavior.
- Fixed cases where guests could remain stuck waiting for approval.
- Improved room lifecycle and connection handling.
- Fixed various playback and synchronization issues.

### 🎵 Music Experience
- Improved playback stability.
- Improved queue synchronization.
- Improved player state handling.
- Improved overall app responsiveness.

### 👥 Music Together
- Improved Online Together sessions.
- Better room management.
- Improved join flow.
- Improved host and guest state synchronization.
- Better handling when a host leaves a room.
- Improved reconnect behavior.

### ⚡ Performance & Stability
- Reduced unnecessary state updates.
- Improved session reliability.
- Fixed minor UI and backend integration issues.
- Improved overall application stability.
