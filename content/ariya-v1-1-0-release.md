# Ariya v1.1.0 is Here! 🎵

Ariya v1.1.0 brings exciting new features, a refined UI, and significant improvements to your music experience.

## What's New

### ✨ New Features
- **Smart Shuffle**: AI-powered shuffle that learns your listening patterns and creates personalized mixes.
- **Lyrics Translation**: Real-time translation for lyrics in 50+ languages, powered by on-device ML.
- **Custom Themes**: Create and share your own color themes with the new Theme Builder.
- **Sleep Timer**: Set a timer to automatically stop playback — perfect for falling asleep to music.

### 🎨 UI & Design
- **Redesigned Now Playing**: Full-screen album art, smoother animations, and gesture controls.
- **Dynamic Island Support**: Live activity integration for supported devices.
- **Improved Dark Mode**: Deeper blacks, better contrast, and automatic switching based on system theme.
- **Refined Glassmorphism**: Updated YDS 2.2 with sharper edges and better performance.

### 🎵 Music Experience
- **Gapless Playback**: Seamless transitions between tracks for live albums and classical music.
- **Enhanced Queue**: Drag-to-reorder, swipe-to-remove, and smart queue suggestions.
- **Improved Offline Mode**: Better download management, auto-download favorites, and storage optimization.
- **Audio Quality Selector**: Quick-switch between Normal, High, and Lossless (where available) from the player.

### 👥 Music Together
- **Shared Queues**: Collaborative playlist building in real-time with friends.
- **Reaction Emojis**: React to tracks playing in a shared session.
- **Host Controls**: Granular permissions for co-hosts and guests.
- **Session History**: View past shared sessions and replay the tracklist.

### ⚡ Performance & Stability
- **Faster Startup**: 40% reduction in cold start time through lazy loading and baseline profiles.
- **Memory Optimization**: Reduced memory footprint by 25% during playback.
- **Battery Efficiency**: Optimized background sync and network usage.
- **Crash Fixes**: Resolved top-reported crashes from v1.0.1.
